# prototype-kit

Mengubah screen Figr/React menjadi prototype HTML statis berbasis design system di `.pawang/prototype/`.

## Pasang

```bash
npx skills add pawangai/pawang --skill prototype-kit -a opencode
```

## Dependensi

- Python 3
- Node.js/npm
- Jaringan untuk `lucide-static`

## Peringatan

- Plan-first: berhenti untuk persetujuan rencana dan estimasi sebelum menulis file.
- Jangan menulis `prototype/` di akar repo; output hanya di `.pawang/prototype/`.
- Script di `scripts/` berjalan dengan hak akses agent.
