# Prototype Kit

> Generated oleh `scripts/sync-plugin.mjs`; jangan edit manual. Jalankan `npm run plugin:sync`.

Mengubah screen Figr/React menjadi prototype HTML statis di .pawang/prototype/.

## Isi

- `skills/prototype-kit/` - skill Prototype Kit, references, dan script pendukung.

## Pasang

- Claude Code: `/plugin install prototype-kit@pawang`.
- ChatGPT/Codex: Codex `codex plugin marketplace add pawangai/pawang`, atau workspace admin impor marketplace. Publik setelah submit.
- Perplexity: impor folder `plugins/prototype-kit` dari repo GitHub.
- Gemini CLI: `gemini skills install https://github.com/pawangai/pawang.git --path skills/prototype-kit --scope workspace --consent`.

## Dependensi

- Python 3
- Node.js/npm
- jaringan untuk lucide-static
