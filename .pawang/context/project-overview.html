Project overview

Ringkasan

Skill & workflow engine agent otonom berbasis spec; state di .pawang (HTML via kit.js), satu skill besar dengan references progressive disclosure.

Masalah

Alur kerja agent sering ad-hoc: spec, verifikasi, audit, dan riwayat tidak konsisten. Pawang menyatukannya dengan dua gerbang manusia.

Pengguna

Developer yang memakai agent otonom (opencode/Claude) untuk membangun perangkat lunak.

Stack

  • Node.js >= 18
  • ESM (.mjs)
  • zero dependency
  • kit.js deterministik

Data

  • Tanpa database; state JSON tertanam di HTML .pawang
  • Riwayat di .pawang/history

UI/UX

Laporan HTML yang mengikuti token project; font-size dasar ikut project.

Deployment

Paket npm (npx pawang init) + skill dipasang per pengguna/proyek.

Batasan

Dua gerbang manusia (review spec, izin commit/merge); offline-friendly; dokumen Bahasa Indonesia; docs/ hanya brownfield.
