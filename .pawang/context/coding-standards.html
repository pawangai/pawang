konvensi kode

Coding standards

Dokumen

  • Semua dokumen skill Bahasa Indonesia.
  • H1 pola `# Topik - subjudul`.
  • Satu topik per reference; tanpa docs/ (hanya brownfield).
  • Bahan skill dibaca dari zip/.

Kode

  • Zero dependency runtime; ESM .mjs; Node >= 18.
  • Komentar hanya untuk 'mengapa'.
  • Perubahan kit.js wajib lolos npm test.

Kontrak state

  • context/ dan history/ hanya lewat kit.js.
  • .pawang/prototype/ artefak generated prototype-kit (di-commit).
  • Dua kit.js: state CLI dan runtime prototype.

Skill

  • Satu skill besar; kemampuan baru = reference + baris peta.
  • Serap/buat skill lewat skill-creator + skill-precheck.
  • Artefak skill tak dikenal: tanya user.

Prototype

  • Lane A prototypes/ tanpa Figr; lane B figr/ -> prototype/ -> .pawang/prototype/.
  • Ada Figr: DS Figr menang atas prototypes/theme.css.
  • Font-family + font-size dasar ikut project; ukuran lain em.
